## How I Build

我希望每个公开项目都能说明四件事：

1. 它解决什么真实问题；
2. 为什么采用这样的设计；
3. 已经验证了什么；
4. 还存在哪些限制。

我重视安全边界，但不希望把它变成 Agent 停滞不前的借口。好的工程约束应当防止未经授权或不可追溯的行为，同时让正常工作继续向前。
